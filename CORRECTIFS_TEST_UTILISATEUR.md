# Correctifs des tests utilisateurs

- Le bandeau de partie rappelle le mode actif et la région éventuelle.
- La correction détaille désormais chaque compétence réellement évaluée (numéro, nom, préfecture, localisation).
- Lorsque le nom est fourni comme indice, il ne compte pas dans les trois compétences évaluées.
- Une localisation non sélectionnée ou incorrecte est indiquée explicitement.

Attention : le barème original est conservé ; les tests navigateur restent à effectuer.
