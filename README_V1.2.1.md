# Atlas GOTRM v1.2.1 — Fiche RPG immersive

- Ajoute le rang, le niveau et une barre d’XP au panneau de personnage.
- Rapproche les cartes de progression de la fiche de personnage.
- Compacte les contrôles de synchronisation sans changer leurs actions.
- Conserve les clés localStorage, les requêtes Supabase, la progression et les modes de jeu.

## Installation
1. Exporte ta progression avant le déploiement.
2. Remplace les fichiers du site à la racine de la branche main sur GitHub Pages.
3. Attends le déploiement, puis recharge avec Ctrl+F5.
4. Vérifie le profil invité, le profil connecté, les XP, le rendu mobile et l’accès aux sauvegardes.

La synchronisation reste manuelle. La version a été vérifiée statiquement ; les parcours navigateur doivent encore être testés.
