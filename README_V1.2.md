# Atlas GOTRM v1.2 — Royaume du Cartographe

Refonte visuelle globale basée sur v1.1. Aucune modification de la logique du jeu, des clés Supabase, des données locales ou des politiques RLS.

## Déploiement

1. Exporter la progression dans Atlas GOTRM et conserver le fichier.
2. Sauvegarder les fichiers actuels du dépôt GitHub.
3. Décompresser l’archive, puis importer les fichiers à la racine de la branche main (pas le dossier parent).
4. Attendre la fin du déploiement GitHub Pages puis forcer le rechargement (Ctrl+F5).
5. Tester l’accueil, les quatre modes de jeu, la carte, l’encyclopédie, les statistiques, le profil et les actions cloud.

## Fichiers nouveaux

- royaume-v1.2.css : couche de design global
- portrait-cartographe.webp : illustration décorative recadrée depuis la maquette approuvée

La synchronisation reste manuelle. Ne pas écraser une sauvegarde cloud sans comparer les progressions.
