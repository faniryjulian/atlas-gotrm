# Atlas GOTRM V0.6.5 — zoom tactile

Correctif du pincement à deux doigts sur la carte mobile. Conserve le menu burger, le bouton Commencer, les XP et le tableau de bord de la V0.6.4.

## Installation GitHub Pages
Remplacer les trois fichiers `index.html`, `style.css` et `app.js` à la racine du dépôt. Ne pas effacer les données du navigateur.

## Vérification
Sur smartphone, lancer un exercice : glisser avec un doigt pour déplacer la carte, pincer avec deux doigts pour zoomer/dézoomer, vérifier les boutons + et −.
